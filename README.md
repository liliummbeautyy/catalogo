# Lilium Beauty · Catálogo

Web pública con los diseños de Lilium Beauty. Las clientas ven los diseños y sus precios, pueden pedir uno o escribir un mensaje sin necesidad de cuenta.

Los diseños, precios y datos de contacto se gestionan desde la app de Lilium Beauty (sección **Catálogo**). Lo que se cambia allí aparece aquí al momento.

Es una web estática: GitHub Pages la publica tal cual.
